2. 背景與概念解釋

影片壓縮係透過 降低 bitrate（位元率） 同 縮小解像度 嚟減少檔案大小：

  • Bitrate（位元率）： 每秒用幾多數據嚟儲存影片。愈高 = 畫質愈好但檔案愈大。
  • Resolution（解像度）： 影片嘅像素尺寸。愈大 = 畫面愈細緻但檔案愈大。
  • Codec（編碼器）： 用嚟壓縮影片嘅演算法。WebM（VP9）通常比 MP4（H.264）更高效。

我哋嘅工具使用瀏覽器內建嘅 MediaRecorder API 進行壓縮，支援三種壓縮程度：

  • 高畫質（少壓縮）： 檔案稍大，畫質接近原片。
  • 中畫質（平衡）： 檔案同畫質之間嘅平衡點。
  • 低畫質（最大壓縮）： 檔案最小，適合網絡分享。

3. 實際應用場景

  • 電郵附件： 將影片壓縮到 25MB 以下以符合電郵限制。
  • 社交媒體分享： WhatsApp、Telegram、Discord 對影片大小有限制。
  • 網站優化： 壓縮網站上嘅影片以提升載入速度。
  • 手機儲存空間： 將手機影片壓縮後儲存，慳位。
  • 雲端備份： 壓縮後上傳，節省雲端儲存空間。

4. 使用步驟

  1. 上傳影片： 點擊或拖曳 MP4/WebM/MOV 檔案到上傳區域。
  2. 預覽： 確認影片已正確載入，檢查片長同尺寸。
  3. 設定參數：
    • 畫質：高／中／低
    • 解像度：原始／75%／50%
  4. 壓縮： 點擊「開始壓縮」，等待處理完成。
  5. 下載： 點擊「下載影片」儲存壓縮後嘅檔案。

2. Background & Technical Concept

Video compression reduces file size by lowering bitrate and reducing resolution:

  • Bitrate: How much data is used per second. Higher = better quality but larger file.
  • Resolution: The pixel dimensions. Larger = more detail but larger file.
  • Codec: The algorithm used for compression. WebM (VP9) is generally more efficient than MP4 (H.264).

Our tool uses the browser's built-in MediaRecorder API with three compression levels:

  • High (less compression): Slightly larger, quality close to original.
  • Medium (balanced): Sweet spot between size and quality.
  • Low (max compression): Smallest file, ideal for sharing.
