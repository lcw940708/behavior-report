2. 背景與概念解釋

Markdown 係由 John Gruber 喺 2004 年創造嘅輕量級標記語言，目標係做到「易寫易讀」。主要特色包括：

  • 純文字格式： 任何文字編輯器都可以打開同編輯。
  • 語法簡單直觀： 例如用 # 表示標題，用 ** 表示粗體。
  • 秒級轉 HTML： Markdown 文件可以快速轉換為結構化嘅 HTML。
  • 廣泛應用： GitHub、Stack Overflow、Notion、Reddit 等都支援 Markdown。
