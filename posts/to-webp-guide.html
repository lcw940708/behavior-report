2. 背景與概念解釋

WebP 係 Google 喺 2010 年推出嘅圖片格式，專門為網絡傳輸而設計。佢支援有損同無損壓縮，仲支援透明通道（Alpha）同動畫——即係一個格式可以取代 PNG、JPG 同 GIF 三個格式。

WebP 嘅核心技術係基於 VP8 影片編碼嘅幀內壓縮，比起傳統 JPEG 嘅 DCT 壓縮更加高效。簡單講：同樣畫質，WebP 細 30-50%；同樣 size，WebP 靚好多。

2. Background & Technical Concept

WebP is an image format developed by Google in 2010, designed specifically for web delivery. It supports both lossy and lossless compression, transparency (alpha channel), and animation—meaning one format can replace PNG, JPG, and GIF.

WebP's core technology uses intra-frame compression based on the VP8 video codec, which is more efficient than JPEG's DCT compression. Simply put: same quality, WebP is 30-50% smaller; same size, WebP looks better.

Our tool uses pure client-side technology: static images use Canvas to output WebP, and animated GIFs use the magic-webp library. All files are processed in your browser—never uploaded to any server. 100% privacy-safe.
