2. 背景與概念解釋

圖片縮放（Image Resizing）係指改變圖片嘅尺寸（寬度同高度），同時保持或調整圖片嘅外觀比例。呢個操作喺數位內容製作中非常常見，例如將高解析度相機照片縮小到適合網站使用嘅尺寸。

縮放時最重要嘅概念係「長寬比例」（Aspect Ratio）——即圖片寬度與高度嘅比例關係。如果唔保持比例，圖片會被拉伸或壓扁，導致變形。我哋嘅工具採用 HTML5 Canvas 技術，支援「保持比例」功能，確保縮放後嘅圖片唔會變形，所有運算喺你嘅瀏覽器內完成，圖片由頭到尾都唔會離開你嘅裝置。

3. 實際應用場景

  • 社交媒體貼文製作：將圖片調整到 Instagram、Facebook、YouTube 等平台嘅推薦尺寸。
  • 產品圖片優化：將高解析度產品相縮小到電商平台要求嘅尺寸，同時保持清晰度。

4. 使用步驟

  1. 上傳圖片：點擊或拖曳上傳 JPG、PNG 或 WebP 圖片。
  2. 設定尺寸：輸入你想要嘅寬度或高度，系統會自動計算另一邊（如果開啟「保持比例」）。
  3. 縮放圖片：點擊「縮放圖片」按鈕，系統會即時生成縮放後嘅圖片。
  4. 下載結果：預覽無誤後點擊「下載圖片」，即可儲存 PNG 檔案。
