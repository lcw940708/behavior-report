Text case conversion is a basic text editing operation that transforms English letters between different case formats. Key modes include:

  • UPPERCASE: All letters become uppercase—ideal for headings, emphasis, or acronyms.
  • lowercase: All letters become lowercase—ideal for body text and code variables.
  • Title Case: The first letter of each word is capitalized—ideal for article titles and book names.
