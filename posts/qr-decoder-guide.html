2. 背景與概念解釋

QR Code（快速響應碼）係一種二維條碼，可以儲存文字、網址、聯絡資訊等多種數據。解碼（Decoding）係指從 QR Code 圖片中提取出編碼嘅數據內容，將圖像轉換返做原始文字或資訊。

現代瀏覽器可以透過 JavaScript 函式庫（如 jsQR）實現純前端 QR Code 解碼。用戶上傳圖片後，瀏覽器會讀取圖片像素數據，透過演算法識別 QR Code 嘅定位圖案（Finder Patterns）並解碼內容。所有處理過程喺你嘅瀏覽器內完成，圖片由頭到尾都唔會離開你嘅裝置。

3. 實際應用場景

  • 提取設計稿資訊：設計師可從設計稿中嘅 QR Code 提取內容，快速驗證正確性。
  • 備份 QR Code 數據：將實體 QR Code 拍照後解碼，提取內含嘅文字或聯絡資訊。
